# Configuration reference

Every value the runtime renders comes from a single object,
`window.PROFILE_CONFIG`, defined in `js/config.js` (demo) or generated by the
editor on export. The runtime merges your object over built-in defaults, so any
field you omit keeps its default.

The dashboard starts with **Tokyo Nights** and a neutral identity. Other templates are **Alpine**, **Northern Lights**, **Coastline**, **Wildflower**, and **Evergreen**. Template previews and applications use your display name (or username) and avatar. No template includes default audio.

Templates are wallpaper and styling presets. The three profile layouts are **Centered** (`guns`, Example 1), **Split** (`modern`, Example 2), and **Fullscreen** (`portfolio`, Example 3). Every layout supports the same widget pages and smooth one-section navigation. Older layout IDs migrate to these three when validated. Applying a template copies only the categories checked in the selection menu and preserves the account name and avatar.

All keys are **PascalCase**. `ValidateConfig` coerces types, clamps numeric
ranges, strips unsafe URLs, and returns a list of `Warnings` for anything it
changed or ignored.

The tab title uses the profile's `DisplayName`. `Meta.AnimatedTitle` animates it
on the public profile. Embedded previews leave the iframe title alone.

## Effects

`Effects.Username` selects `none`, `rainbow`, `sparkle`, `pulse`, `fuzzy`, or `typewriter`. Glitch is
configured separately under `Effects.NameGlitch`.

## Widgets

`Widgets.Discord` contains `Enabled`, `Name`, `Icon`, `Online`, `Members`, and
`Invite`. These are manual community details, with a link to the invite URL.

`Widgets.Clock` contains `Enabled`, `Timezone` (an IANA identifier such as
`Europe/London`), and `Label`. Invalid zones fall back to `Europe/London`.

`Widgets.Quote` contains `Enabled`, `Text` (up to 800 characters), and `Author`.

## Music

| Field | Type | Default | Range / notes |
|---|---|---|---|
| `Enabled` | bool | `false` | |
| `Title` | string | `""` | max 120 |
| `Artist` | string | `""` | max 120 |
| `Src` | URL | `""` | Required when enabled. |
| `Cover` | URL | `""` | |
| `Tracks` | array | `[]` | Up to 32 `{ Title, Src, Cover, Lyrics }` tracks. |
| `TrackIndex` | number | `0` | Initial track index, clamped to the playlist. |
| `Volume` | number | `0.7` | 0–1 |
| `Loop` | bool | `true` | |
| `Autoplay` | bool | `false` | Attempt playback on load (falls back to first gesture). |

If `Enabled` is true and `Src` is empty, the player is hidden and a warning is
emitted.

`Title`, `Src`, and `Cover` describe the selected track; the editor keeps these
in sync with playlist edits. Each track's `Lyrics` accepts up to 40,000 characters
of timestamped LRC, such as `[00:19.001]A lyric line`. The copied music controls
switch tracks and seek when a lyric is clicked. `Loop` repeats the playlist when
it contains multiple tracks. Local track audio, covers, and custom fonts are
included in ZIP exports.

## Social

| Field | Type | Default | Range / notes |
|---|---|---|---|
| `IconSize` | number | `34` | 18–72 |
| `Style` | enum | `"glow"` | `glow` \| `boxed` \| `plain`. |
| `Monochrome` | bool | `false` | Render icons in a single color. |
| `Links` | array | `[]` | Up to 24 items. |

`Links[]` items: `Name` (max 60, set automatically from the chosen platform
when added through the editor), `Service` (registered platform slug), `Url`,
`Icon` (slug or URL), `Color` (optional icon color), `Mode` (`link` or `copy`),
and `CopyText` (up to 200 characters).

The editor shows the service prefix as noneditable text, with a separate
**Profile path** input. For example, choosing Bandcamp fixes the prefix to
`https://bandcamp.com/`. Changing service resets its name, icon, and URL every
time. Validation enforces the same prefix and origin for imported configurations
and exports. Unknown services are dropped. Freeform website origins are not
offered. `Mode: "copy"` copies `CopyText` when clicked.

### Icon slugs

`Icon` may be a built-in slug or an image URL. The searchable picker includes
the full catalog in `js/icons.js` and the original SVGs in `js/reference-icons.js`.
Common service slugs include:

`applemusic`, `bandcamp`, `bilibili`, `bluesky`, `buymeacoffee`, `cashapp`,
`devdotto`, `discord`, `dropbox`, `ebay`, `etsy`, `facebook`, `figma`, `gmail`,
`github`, `gitlab`, `instagram`, `kick`, `kofi`, `lastdotfm`, `linktree`,
`medium`, `patreon`, `paypal`, `pinterest`, `pixiv`, `reddit`, `roblox`,
`rumble`, `snapchat`, `soundcloud`, `spotify`, `steam`, `substack`, `telegram`,
`threads`, `tiktok`, `twitch`, `venmo`, `vimeo`, `vk`, `whatsapp`, `x`,
`youtube`.

For a custom image, set `Icon` to a URL or an uploaded image (the editor stores
uploads as Blobs in IndexedDB and the export writes them into `assets/`). Any slug not
in the list renders nothing, so prefer a URL in that case.

## Cursor

| Field | Type | Default | Range |
|---|---|---|---|
| `Image` | URL | `""` | |
| `HotspotX` | number | `4` | 0–128 |
| `HotspotY` | number | `4` | 0–128 |

Uploaded raster and SVG cursors are normalized to a maximum of 64 pixels on
either axis, and hotspots are scaled and clamped to the resulting image.
Adding or changing a cursor updates the preview without reloading the page.

## Portfolio

`AboutTitle`, `AboutText`, and `AboutDetails` bind to the saved about sections.
`Tags` contains up to 12 interest labels. `ProjectTitles` names the existing
gallery sections; `Projects` contains up to 24 cards with `Section` (zero-based),
`Title`, `Description`, `Image`, `Service`, and `Url`. The editor locks project URL
prefixes just like social links. Local project images are bundled in exports.

`LastFm` contains `Enabled`, `UserName`, `Scrobbles`, and `Artists`. Counts are
entered manually. Reverie's final section uses `Widgets.Quote`.

## Validation summary

- Non-object input is replaced with defaults (+ warning).
- Numbers are parsed and clamped; invalid numbers use the default.
- Booleans accept `true`/`false`, `1`/`0`, `"true"`/`"false"`, `"1"`/`"0"`.
- Strings are truncated to the limits above.
- URLs starting with `javascript:`, `vbscript:`, or `data:text/html` are
  replaced with `""` (+ warning).
- Unknown enum values fall back to the documented default.
- `Badges[]` and `Social.Links[]` are capped at 24 each; invalid entries are
  dropped.
- `Social.Links[]` URLs remain under the selected service's fixed prefix.
  Choosing a platform updates its name and icon; custom icon artwork is also
  available. Badge selection updates the label and icon together.

`TemplateRevision: 2` identifies cleaned templates. `MediaCredits` is an array of selected media attribution records (title, author, license, source). Uploaded asset references are stored as `asset:<id>` in drafts, resolved to object URLs at runtime, and converted to data URLs only for portable JSON export.
